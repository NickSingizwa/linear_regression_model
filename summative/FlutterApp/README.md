# Life Expectancy Predictor (Flutter)

Single-page mobile app that sends the 8 health indicators to the prediction API
and displays the predicted life expectancy (or a validation error).

The app source lives in `lib/main.dart` with dependencies in `pubspec.yaml`.
The platform folders (`android/`, `ios/`, `web/`, ...) are generated by Flutter
for your installed SDK. Generate them without disturbing the custom source:

```bash
# run from the summative/ directory (one level above this folder)
mv FlutterApp _flutter_src
flutter create FlutterApp
cp _flutter_src/lib/main.dart        FlutterApp/lib/main.dart
cp _flutter_src/pubspec.yaml         FlutterApp/pubspec.yaml
cp _flutter_src/analysis_options.yaml FlutterApp/analysis_options.yaml
cp _flutter_src/README.md            FlutterApp/README.md
rm -rf _flutter_src

cd FlutterApp
flutter pub get
flutter run                 # select an Android/iOS emulator or a connected device
```

Before running, set your deployed API URL at the top of `lib/main.dart`:

```dart
const String kApiBaseUrl = "https://linear-regression-model-z9ly.onrender.com";
```
